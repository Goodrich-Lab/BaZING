# BaHZING 1.1.0

* Added `Ridge_BaHZING_Model()` for ridge-based hierarchical modeling.
* Added `ZIP_qgcomp()` for comparison analyses using quantile
  g-computation.
* Added reproducible per-chain JAGS initialization through the `seed`
  argument.
* Added optional posterior output from `BaHZING_Model()`.
* Added parallel execution of independent JAGS chains on supported systems.
* Improved posterior summarization and taxonomy-prefix handling.
